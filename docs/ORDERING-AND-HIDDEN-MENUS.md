# 排序与隐藏菜单交互

用户要求：控制项目实际左右顺序；未固定项目点击时不把全部图标展开到主菜单栏，以避开刘海。

设计：在列表中提供左右移动一位和拖到目标之前。列表按物理位置从左到右排列；跨固定 / 收起分组使用图钉，拖放只改变同组顺序。移动后读实际位置验证并保存顺序，恢复布局时应用保存的顺序。

打开面板保持当前收起状态。扫描包含屏幕外菜单栏项目，保留 AX 元素。未固定项目只尝试 AXPress / AXShowMenu，不展开、不移动到主菜单栏，也不在旧坐标发鼠标事件。操作接口不支持时明确提示；不把接口接受事件当作所有应用兼容性通过。

兼容性边界：辅助功能不能将任意第三方 NSStatusItem / 自定义 popover 搬进 MenuPin 的窗口。独立栏是入口，真正菜单由所属应用绘制；隐藏位置直接唤起需逐个应用测试。Ice 的通用实现会临时显示目标项，不能据此承诺所有应用全程不在主菜单栏出现。本次采取严格不展开策略，暂不加入自动临时显示兜底。

验证：独立测试覆盖排序边界、拖放序列、未固定的打开策略、屏幕外枚举；编译及演示交互验证。每次新构建须完成检查后再替换安装版本；辅助功能授权由用户在系统设置中操作。1.2 使用 List/onMove 和左侧 ≡ 拖拽柄，插入位置可在同组内选择。
