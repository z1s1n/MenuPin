# MenuPin · 菜单栏管理器

目标：参考 Chrome 扩展列表，用图钉管理 macOS 右上角菜单栏项目，点击列表打开项目原菜单。

界面：SwiftUI 原生弹出面板，中文，搜索，固定 / 已收起分组，项目图标和名称，图钉，更多菜单；底部设置、刷新和展开 / 收起。未授权时显示辅助功能引导，无虚构的在线项目。

实现：AppKit NSStatusItem 提供入口与收起分隔符。AX 枚举各进程的 extras menu bar；CGWindow 元数据作为可见图标的补充。CGEvent 模拟 Command 拖动调整项目到分隔符两侧。移动前展开、取得当前坐标，移动后重新扫描并验证目标区域，再更新持久设置。列表点击保持当前收起状态并刷新项目引用；隐藏项目仅 AXPress / AXShowMenu，固定项目可尝试屏幕内鼠标点击。无法识别、不可移动或缺权限时明确报错。

状态：UserDefaults 保存项目标识、图钉选择和自动收起偏好；实际区域以当前坐标为准。退出时移除分隔符，使所有图标恢复。默认启动展开，不自动改变用户已有布局；只在用户操作或启用自动收起后改变布局。

范围：macOS 13+，本次构建 arm64。无网络、无第三方依赖、无私有 API。刘海 / 空间不足和不可移动系统项目有系统限制，界面提供 Command 拖动备用方式。辅助功能需要用户在系统设置授权，应用本身不能代为授权。演示模式独立标记，不访问或操作其他应用。

验证：独立 Swift 测试覆盖跨屏坐标、分类、稳定项目标识、过滤和搜索；实际 Swift 编译、app 签名检查、演示 UI 渲染、正常启动检查。未取得权限时不能把第三方移动和原菜单点击宣称为已实测。
